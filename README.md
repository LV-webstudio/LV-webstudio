## Products (information only, code is private)
- [Shania CRM](https://github.com/LV-webstudio/shania-crm-info) — web CRM for real-estate agencies, with AI assistant and the Shania Voz voice receptionist.
- [Shania Legal](https://github.com/LV-webstudio/shania-legal-info) — Spanish and EU legislation search and citation checking.
- [Shania Conta](https://github.com/LV-webstudio/shania-conta-info) — bookkeeping with VERI*FACTU records for freelancers and small businesses.
- [Shania Lawnmower](https://github.com/LV-webstudio/lawnmower-info) — website auditing app and its Analitics engine.
- [Shania Timing](https://github.com/LV-webstudio/shania-timing-info) — live view of several AI sessions working on a project.
- [Speccy OS](https://github.com/LV-webstudio/speccyos-info) — retro front-end for Android.
- [Crónicas de Iberia](https://github.com/LV-webstudio/cronicas-de-iberia-info) — open-world survival adventure in pre-Roman Iberia (in development).
